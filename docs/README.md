# Prosperity Docs

This directory holds the working context needed for research, implementation, and iteration during the challenge.

Read in this order:

1. `challenge_rules.md`
2. `repo_workflow.md`
3. `trader_architecture.md`
4. `backtesting_process.md`
5. `rounds/round1/overview.md`
6. `rounds/round1/active_plan.md`
7. Product-specific notes for the current task

File roles:

- `challenge_rules.md`: durable Prosperity mechanics and constraints.
- `repo_workflow.md`: repo-specific structure and operational workflow.
- `trader_architecture.md`: intended software design and strategy decomposition.
- `backtesting_process.md`: experiment discipline and evaluation rules.
- `references_external.md`: concise map of useful external repos, writeups, and code.
- `rounds/`: round-specific hypotheses, plans, and logs.

Principles:

- Keep docs concise and decision-oriented.
- Put stable information in top-level docs.
- Put changing research in `rounds/roundN/`.
- Record conclusions, not notebook-level noise.
- Prefer one clear source of truth per topic.
